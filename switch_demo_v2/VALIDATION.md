# Demo v2 验证记录

日期：2026-10-03。以下结果证明自研模拟器的指定行为，不代表华为真机或 eNSP 兼容性验收。

## 自动行为检查

17 项 unittest 通过，覆盖：

- 健康拓扑的往返通信。
- A～D 两轮修复及中间失败状态。
- A 中先恢复本地通信，C 中去程成功而回程失败。
- E 配置写入后仍然物理 DOWN，普通配置无法消除信号异常。
- 错误设备、接口、视图和 VLAN 参数。
- 必要 VLAN 与静态绑定要求。
- VLANIF 管理关闭、路由有效性和链路状态传播。
- 终端会话隔离、实验重置和旧证据失效。
- 修改场景编号不会改变同一设备状态的探测或建议。
- A～E 均返回至少一条结构化手册出处，健康基线不伪造故障出处。
- 助手专用 API 不泄露场景编号和预设答案，不同设备保持独立命令行会话，旧实验命令会被拒绝。

## 浏览器操作检查

使用本机 Edge / Playwright 执行实际页面流程：

- 五个场景通过界面选择，向导检查，切换设备，粘贴命令并按 Enter。
- 点击场景后展示 PDF 页码、正文页码和章节；挑战模式保留页码但隐藏章节摘要。
- 内嵌 PDF 与原文件 SHA-256 一致；本地服务支持 PDF 分段读取，小窗可在两条出处间切换页码。
- A～D 分两轮恢复；E 形成未解决物理问题的交接结果。
- 多行输入遇到错误后停止，保留正确的当前视图。
- 双击设备、拖动布局、命令历史与 Tab 补全。
- 独立助手窗口共享当前实验，能够打开指定设备的独立终端。
- 桌面与窄屏没有水平溢出；未发现 JavaScript 页面错误或外部网络资源请求。
- `/device` 与 `/assistant` 分别在 960×1080 半屏视口通过横向、纵向无溢出检查，关键输入控件保持可见。
- 从 PyInstaller 生成的 `switch-lab.exe` 启动服务后重复以上验收，无需运行源码或项目虚拟环境。

## 当前限制

- 拓扑连接固定，拖动仅改变显示位置。
- 只有计划中用到的命令子集，真实 VRP 的别名、参数组合、交互确认和所有转发细节不在覆盖范围内。
- 探测与报文动画均为状态模型生成，不是实际网络抓包。
- 规则向导每轮读取一组固定观测后给出下一步，不是正在开发的大模型助手。
- 光信号输出为明确标注的模拟观测；不能仅凭该观测确定是光纤还是模块故障。
- 重启服务清除状态；当前记录导出包含最近 40 条操作。
