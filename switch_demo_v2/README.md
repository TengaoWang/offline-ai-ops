# 驻点网络实验台 Demo v2

固定拓扑、可输入命令的设备终端、五种多步排障场景，以及不依赖模型的逐步排障向导。保留上一版 `switch_demo/`。

## 启动

在 Windows 演示电脑上，解压完整目录后双击 `启动演示.bat`，程序会自动打开浏览器。电脑需要安装 Python 3.10 或更高版本，不需要安装任何 Python 第三方包。

独立 EXE 交付目录使用 `switch-lab.exe --open` 启动，不要求目标电脑安装 Python；也可以双击目录中的 `启动独立版.bat`。开发电脑通过 `build_standalone.ps1` 重新生成该目录。

在 `offline-ai-ops` 目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 switch_demo_v2\server.py
```

打开 http://127.0.0.1:8878 。支持 Python 3.10+，服务只使用标准库，无需安装 eNSP、Ollama 或联网。

“查看出处摘要”会在页面内显示由原始 PDF 直接生成的对应页预览；引用跨页时可以在小窗内翻页。“在新窗口打开完整原件”会打开同一份内嵌 PDF 并定位页码。默认读取随 Demo 打包的 `assets/华为S系列园区交换机维护宝典.pdf`，所以复制整个 `switch_demo_v2/` 目录后仍可使用；也可以在启动前通过 `SWITCH_DEMO_MANUAL` 覆盖路径。

打包时必须保留整个 `switch_demo_v2/` 目录，尤其是 `assets/`，其中包括 PDF 和 `manual-pages/` 引用页预览。内嵌 PDF 的 SHA-256 为 `FE9E2CE0CECD9A2542D492B91DFFB05C86C56B99E9299BF501E0A36263C61B23`，与本次提供的原文件一致。

- 主界面：`/`，拓扑、终端、向导并排。
- 独立模拟器：`/device`，按 960×1080 左半屏优化。
- 独立向导：`/assistant`，按 960×1080 右半屏优化。

答辩展示时分别打开 `/device` 和 `/assistant`，使用 Windows 分屏将两个浏览器窗口贴靠左右。模拟器窗口内仍可完整看到 A～E、当前现象、拓扑、手册出处、探测结果和设备终端。

正式离线助手通过 `http://127.0.0.1:8878/api/v1` 连接模拟器。接口只提供可观察证据，不返回场景编号或预设答案；对接格式见 [`ASSISTANT_API.md`](ASSISTANT_API.md)。

## 操作

1. 左侧选择 A～E 或随机场景。
2. 业务现象下方会显示本场景引用的手册页码；“查看出处摘要”可核对章节、正文页码和故障机制。组合场景明确标注为依据手册机制构造。
3. 右边点击“开始排查”。
4. 双击指定设备打开终端，逐行输入建议命令，或复制粘贴后按 Enter。
5. 点击“修改后复检”。每轮只指导一处修复，直到恢复或明确需要现场处理。

命令帮助 `?`；Enter 执行，Shift+Enter 换行，↑↓ 历史，Tab 补全，Ctrl+L 清屏。多行命令出错后暂停余下命令。端口、VLAN、路由与 ARP 均有状态；错误操作不会自动变成正确修复。修改配置后旧探测结果失效。

## 场景（排练用答案）

| 场景 | 问题 | 预期结果 |
|---|---|---|
| A · 只诊断 | SW1 GE0/0/1 管理关闭；SW1 上联缺 VLAN 10 | 助手定位根因并给出建议，不自动修改 |
| B · 只诊断 | SW1 PC1 接入口为 VLAN 20；SW3 服务器接入口为 VLAN 20 | 助手定位两个错误 VLAN，不自动修改 |
| C · 自动修复 | SW2 无服务器路由；SW3 回程下一跳错误 | 先体检，再选择“场景 C：路由故障修复”并输入“帮我解决故障” |
| D · 自动修复 | SW2、SW3 保留对端旧静态 MAC | 先体检，再选择“场景 D：静态 ARP 修复”并输入“帮我解决故障” |
| E · 转人工 | SW3 缺回程；互联链路持续信号缺失 | 告知用户检查线缆、光纤或模块，不伪造修复 |

健康重置会创建新的实验，不能作为修复证据。挑战模式只隐藏场景标题与选择状态，不声称具有对抗性防作弊隔离。

左右分屏展示时，模拟器使用 `http://127.0.0.1:8878/device`，离线助手使用 `http://127.0.0.1:8765`。模拟器根页面在窗口宽度不超过 1100px 时也会自动切换到半屏布局。

## 诚实边界

- 拓扑、命令输出和探测为自研简化行为模拟，不是 VRP 镜像、真实交换机或真实 ICMP 发包。
- 探测依据接口、VLAN、路由、地址解析和回程路径计算，不读取故障编号。路由只覆盖此 Demo 所需的单路径静态路由，不实现动态协议或 ECMP。
- 拓扑动画呈现内部模拟路径，是演示解释，不是实际抓包证据。
- 配套向导是规则 Demo，读取设备观测和网络规划，不根据故障编号给答案。没有实时 RAG 或通用聊天能力。
- 手册引用为已经核对的章节页码；光信号缺失文字是明确标注的模拟观测，不声称逐字兼容厂商日志格式。
- 命令仅覆盖帮助中列出的子集，不传入宿主机 Shell。
- 数据存在当前进程内，退出服务即清除。
