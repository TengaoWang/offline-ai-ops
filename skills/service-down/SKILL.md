# 交换机登录排查

通过 SSH / STelnet 登录不了交换机时，检查管理地址是否可达、STelnet 服务是否开启、SSH 源接口和 VTY 用户数。

## 适用场景

- SSH 客户端连不上交换机
- 登录时被拒绝或连接超时

## 采集内容

| 命令 | 在哪里执行 | 作用 |
|---|---|---|
| `ping -n 2 -w 1000 管理地址` | 本机 | 本机到交换机管理地址是否可达 |
| `display ssh server status` | 交换机（回放） | STelnet 是否开启、SSH 源接口 |
| `display users` | 交换机（回放） | 当前 VTY 用户数 |

管理地址默认取本机的默认网关（接入交换机），也可以用环境变量 `OPS_MGMT` 指定。

## 安全边界

只执行白名单内的只读命令。`stelnet ipv4 server enable` 等修改配置的命令只作为建议展示，不会自动执行。
