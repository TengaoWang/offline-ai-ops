# 交换机模拟器后端接入

离线助手只通过 `http://127.0.0.1:8878/api/v1` 与同机交换机模拟器通信。后端先读取健康状态和实验编号，再为每台设备建立独立 CLI 会话；后续命令和复检必须携带同一个实验编号，实验切换后旧编号不得继续使用。

自动诊断只允许执行 `display`、`ping` 和 `ipconfig` 等只读采集命令。`system-view`、`shutdown`、VLAN 修改、静态路由修改和其他配置命令不得进入自动执行器，修复步骤只能展示给现场人员确认。

端到端探测失败只证明当前业务路径不可达。接口状态、VLAN 和路由表必须分别采集并交叉核对；模拟器返回的输出始终标记为 `simulation`，不能作为真实设备验收证据。
