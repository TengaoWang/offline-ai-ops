# 内置离线运维诊断基线

## 磁盘容量只读检查

使用 `df -P` 读取本机各文件系统的容量与使用率；该命令只读取文件系统统计信息，不修改磁盘内容。使用率达到或超过 90% 时应标记为容量警告，并由现场人员确认需要清理或扩容的对象。

使用 `du -sk /tmp` 读取临时目录占用量；该命令只汇总目录大小。目录扫描失败时应报告未能获取，不得伪造数值。

## 服务和进程只读检查

使用 `ps -axo pid,comm` 读取本机进程编号和命令名；该命令不启动、停止或修改进程。采集成功只能证明进程列表可读取，不能单独证明某个业务服务健康。

使用 `netstat -an` 读取本机网络连接和监听状态；该命令不打开或关闭端口。服务故障仍需结合服务状态和日志判断。

使用 `uptime` 读取系统运行时间和负载摘要；该结果用于提供诊断上下文，不应单独推断根因。

`systemctl status nginx` 是 Linux 上读取 nginx 服务状态的命令；如果目标系统没有 systemd 或没有该服务，应将采集标记为失败并继续处理可选检查，不得执行启动或重启操作。

## 日志审计只读检查

使用 `last -n 5` 读取最近登录记录，使用 `who` 读取当前登录会话；两条命令都只读取会话记录。没有输出不等于发生安全事件，需要结合目标系统的日志保留策略人工确认。

日志审计结果只能描述已经采集到的记录。缺少日志、权限不足或命令失败时，必须列入未决项，不能推断不存在异常。

## 安全边界

诊断执行器不得运行 `rm`、`reboot`、`shutdown`、`write memory` 等删除、重启或写配置命令。任何包含 shell 管道、重定向、命令拼接、命令替换、反引号或换行注入的参数都必须拒绝。修复指令只能作为人工建议展示，不能进入自动执行器。
