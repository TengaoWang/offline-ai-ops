## 安全与诚实边界抽查

- `rm`、`reboot`、`shutdown`、`write memory` 以及 `;`、`&&`、管道、反引号、`$()`、重定向、换行注入全部在执行前拒绝。
- 执行列表只能来自已经校验的 `collect.yaml`；AI 只接收采集结果和当轮手册片段。
- AI 发布项需要当轮合法引用编号、逐字证据句和原文支持的建议命令；否则进入 `unresolved`。
- 模型不可用、超时和协议错误分别映射 503/504/502，不转成 200 `extracted` 或 `not_found`。
- SSE 在 `done`/`error` 后关闭连接；运行结果和技能沉淀均由服务端持有。
- `real` 与 `simulation` 由每次运行固化并在 UI 展示，失败不自动回退。

## 保留的失败与修正记录

- 调优前问答曾出现 32–41 秒样例；将问答生成独立限制为 256 token、正文限制为 220 字并把模型上下文限制为 2 个扩展段后，最终留出集单请求最大 28.38 秒。旧失败结果仍保存在本地 `eval/results/`。
- 留出题“业务高峰命令行慢，怎样核查 CPU 异常”在最终自动规则中通过，但人工语义复核发现其原文降级片段主要讨论微突发，未给出足够有用的 CPU 核查步骤，因此对外仍计为失败；有效可回答门禁为 9/10，而不是用关键词命中宣称 10/10。
- 通用“管理员口令遗失”首次错误命中仅适用于特定 Web 设备的恢复场景。最终代码对缺少型号/可用登录方式的问题先追问；提供 `S5700 + Console` 条件后的回归命中“忘记 Console 口登录密码”章节并通过。原错误结果保留在留出文件中。
- 第一次多轮留出运行为 3/5：一个 `extracted` 结果因已丢弃生成答案的命令告警被评测器误判，另一个现场说法“清空原有配置”检索到了存储空间清理。修正安全降级判定并增加公开、确定性的检索词扩展后，同一 5 组回归为 5/5。原 3/5 文件保留。
